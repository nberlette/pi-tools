# Raspberry Pi 5 Model B (5B)

The Raspberry Pi 5 Model B is the latest iteration of the popular Raspberry Pi single-board computer series. It features significant performance improvements, enhanced connectivity options, and increased memory capacity, making it suitable for a wide range of applications from education to professional projects.

Released in June 2024, the Raspberry Pi 5 Model B continues the tradition of providing affordable and versatile computing solutions for enthusiasts and developers alike.

## Specifications

> [!IMPORTANT]
>
> This section is incomplete. Please refer to the [Raspberry Pi 5B Datasheet].

- **Compute**: 2.0GHz quad-core 64-bit Arm Cortex-A76 CPU
  - 512KB/core L2 cache
  - 2MB shared L3 cache
  - plus cryptography extensions
