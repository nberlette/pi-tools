# Raspberry Pi 500

The Raspberry Pi 500 is a compact and powerful all-in-one computer that integrates the Raspberry Pi 5 SoC into a keyboard form factor. Designed for ease of use and portability, the Raspberry Pi 500 is ideal for educational purposes, programming, and general computing tasks.

## Specifications

<img {...diagram} alt="Raspberry Pi 500 Diagram" className="my-4 rounded-lg shadow-md w-full h-auto" />

- **Compute**: 2.4GHz quad-core 64-bit Arm Cortex-A76 CPU
  - 512KB/core L2 cache
  - 2MB shared L3 cache
  - plus cryptography extensions
- **Memory**: 8GB LPDDR4X-4267 SDRAM
- **Wi-Fi**: Dual-band (2.4GHz and 5.0GHz) IEEE 802.11b/g/n/ac Wi-Fi®
- **Bluetooth**: 5.0, BLE
- **LAN**: Gigabit Ethernet
- **USB**: 2 × USB 3.0 port and 1 × USB 2.0 port
- **GPIO**: Horizontal 40-pin GPIO header
- **HDMI**: 2 × micro HDMI® port (supports up to 4Kp60)
- **Video**: H.265 (4Kp60 decode)
- **Graphics**: OpenGL ES 3.1 graphics, Vulkan 1.3
- **Keyboard**: 78-, 79- or 83-key compact keyboard (depending on regional variant)
- **Power**: 5V/4A DC via USB connector
- **Storage**: 32GB Class A2 microSD included
  - microSD card slot for operating system and data storage
