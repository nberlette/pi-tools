# Raspberry Pi 500+

The Raspberry Pi 500+ is the latest release in the Raspberry Pi family of affordable, high-performance single-board computers. Building on the success of the Raspberry Pi 500, the 500+ offers enhanced features and improved specifications, making it an ideal choice for both educational and professional use.

## Specifications

<img {...diagram} alt="Raspberry Pi 500+ Diagram" className="my-4 rounded-lg shadow-md w-full h-auto" />

- **Compute**: 2.4GHz quad-core 64-bit Arm Cortex-A76 CPU
  - 512KB/core L2 cache
  - 2MB shared L3 cache
  - plus cryptography extensions
  - [up to 3.0GHz with overclocking](./#overclocking)
- **Memory**: 16GB LPDDR4X-4267 SDRAM
- **Storage**: Integrated NVMe M.2 slot with 256GB SSD (pre-installed with Raspberry Pi OS)
  - microSD card slot for additional storage
- **Wi-Fi**: Dual-band (2.4GHz and 5.0GHz) IEEE 802.11b/g/n/ac Wi-Fi®
- **Bluetooth**: 5.0, BLE
- **LAN**: Gigabit Ethernet
- **USB**: 2 × USB 3.0 port and 1 × USB 2.0 port
- **GPIO**: Horizontal 40-pin GPIO header
- **HDMI**: 2 × micro HDMI® port (supports up to 4Kp60)
- **Video**: H.265 (4Kp60 decode)
- **Graphics**: OpenGL ES 3.1 graphics, Vulkan 1.3
- **Keyboard**: 78-, 79- or 83-key RGB mechanical keyboard (depending on regional variant)
- **Power**: 5V/5A DC via USB-C connector
- **Included Storage**: 256GB NVMe SSD
